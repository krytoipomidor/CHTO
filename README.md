# CHTO — система бронювання кімнат

Мінімальний вебзастосунок на Django для перегляду кімнат, перевірки доступності й бронювання з підтвердженням електронною поштою.

## Запуск локально

```powershell
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py createsuperuser
.\.venv\Scripts\python.exe manage.py runserver
```

Сайт доступний на `http://127.0.0.1:8000/`, адміністративна панель — на `/admin/`. Додайте типи кімнат і кімнати в адмінці перед створенням бронювань.

У локальному режимі листи виводяться в консоль. Для реального відправлення листів налаштуйте стандартні параметри Django `EMAIL_BACKEND`, `EMAIL_HOST`, `EMAIL_PORT`, `EMAIL_HOST_USER`, `EMAIL_HOST_PASSWORD` і `DEFAULT_FROM_EMAIL`.

## Реалізовано

- Три моделі: тип кімнати, кімната та бронювання.
- Пошук кімнат за типом і періодом; endpoint `/availability/` повертає JSON зі вільними кімнатами для інтерактивної перевірки.
- Створення бронювання з перевіркою часу та перетинів. Очікуване підтвердження займає період так само, як підтверджене бронювання.
- Підтвердження через посилання з email; токен має строк дії 24 години, а зміна стану виконується тільки POST-запитом.
- Адмін-панель для керування типами, кімнатами та бронюваннями.

Тести запускаються командою `.\.venv\Scripts\python.exe manage.py test`.
